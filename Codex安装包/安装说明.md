## 安装

1. 双击 `ChatGPT-Codex-Windows安装程序.exe`。
2. 按 Windows 提示完成 ChatGPT 桌面版安装。
3. 打开 ChatGPT 并登录 OpenAI/ChatGPT 账号。
4. 在界面中选择 **Codex**，然后新建任务或打开本地项目。

安装和使用通常需要联网及可用的 ChatGPT 账号。Codex 的部分功能可能需要相应套餐或使用 API Key；部分功能在不同套餐下可能不可用。

本项目安装包不包含账号、密码、Codex 登录凭据或 Token。
