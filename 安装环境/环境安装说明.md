# GitHub Tools 环境安装

本项目当前只使用 Python 标准库，没有第三方 pip 包；GitHub 操作还依赖 Git。

## Windows 一键安装

进入 `安装环境` 文件夹，双击 `安装环境.bat`。

- 电脑已安装 Miniconda/Conda：自动读取 `environment.yml`，创建名为 `github-tools` 的环境，其中包含 Python 3.11、Git 和 pip。
- 电脑没有 Conda、但已有 Python 3.8+ 和 Git：自动创建项目内的 `.venv` 虚拟环境，并安装 `requirements.txt` 中的依赖。
- 电脑既没有 Conda，也没有 Python：先安装 [Miniconda](https://docs.conda.io/projects/miniconda/en/latest/) 或 [Python](https://www.python.org/downloads/windows/)，再双击安装。

安装脚本不会上传文件，也不会修改 GitHub 仓库。

也可以强制选择一种安装方式：

```bat
安装环境.bat conda
安装环境.bat venv
```

## 手动安装

有 Conda 时：

```powershell
conda env update --name github-tools --file environment.yml
conda activate github-tools
python -m pip install -r requirements.txt
```

没有 Conda 时：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 使用前配置

1. 复制 `projects.example.json` 为 `projects.json`。
2. 在 `projects.json` 填写 GitHub 用户名、Token 和本地项目路径。
3. 在 `config.py` 设置要上传/下载的仓库。
4. 如果新电脑没有相同端口的代理，把 `config.py` 中的代理地址改为本机代理，或设为空字符串。

建议先预览操作：

```powershell
python "1_Github项目上传.py" --dry-run
python "2_Github项目下载.py" --dry-run
```

## 安全提醒

`projects.json` 包含 GitHub Token，不要把它发送给他人，也不要上传到公开仓库。项目已有的 `.gitignore` 默认忽略该文件。
